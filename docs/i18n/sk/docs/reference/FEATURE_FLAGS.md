> Prepínače za behu, ktoré menia správanie OmniRoute **bez opätovného nasadenia**.
> Každý tu uvedený príznak je definovaný v
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — jediný zdroj pravdy. Dashboard aj REST API čítajú z
> tohto súboru, takže tabuľka nižšie je vygenerovaná tak, aby mu zodpovedala 1:1.

---

## Čo sú prepínače funkcií (Feature Flags)

Prepínač funkcií je pomenovaný prepínač (booleovský alebo výčtový), ktorého hodnota sa môže meniť za
chodu a je perzistentná v databáze, bez potreby opätovného nasadenia procesu. Každý
príznak je popísaný `FeatureFlagDefinition` s `key`, `label`,
`description`, `category`, `defaultValue`, `type` a nápovedou `requiresRestart`.

### Poradie rozlíšenia

**Efektívna hodnota** príznaku je rozlíšená pomocou
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) s
tejto priority (najvyššia vyhráva):

1.  **Prepísanie z DB** — hodnota uložená v tabuľke `key_value` pod
    priestorom názvov `feature_flags` (nastavená cez dashboard alebo REST API).
2.  **Premenná prostredia** — `process.env[<KEY>]`, ak je nastavená a nie je prázdna.
3.  **Predvolená hodnota definície** — `defaultValue` zo súboru `featureFlagDefinitions.ts`.

Booleovský príznak sa považuje za **povolený**, keď je jeho efektívna hodnota `"true"`,
"`1`" alebo `"yes"` (pozri `isFeatureFlagEnabled()`).

> [!POZNÁMKA]
> Väčšina príznakov má tiež zodpovedajúcu premennú prostredia s **rovnakým názvom**
> zdokumentovanú v [`ENVIRONMENT.md`](./ENVIRONMENT.md). Prepísanie príznaku z DB
> má prednosť pred touto premennou prostredia. Príznak s
> `requiresRestart: true` je okamžite perzistentný, ale znova sa načíta iba pri spustení procesu
> — jeho prepnutie zobrazí v dashboarde banner **"Reštartovať server"**.

## Prepínanie príznakov

### Dashboard

Prejdite na **Dashboard → Settings → Feature Flags**
(`/dashboard/settings/feature-flags`). Mriežka
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
podporuje:

- **Vyhľadávanie** podľa kľúča alebo popisu a **filtrovanie** podľa kategórie (plus syntetický
  pohľad **Vyžaduje reštart**).
- **Prepínač** pre booleovské príznaky a **rozbaľovací zoznam** pre enum príznaky
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- **Odznak zdroja** pre každý príznak — `DB`, `ENV` alebo `DEF` — zobrazujúci, odkiaľ
  pochádza efektívna hodnota.
- Tlačidlo **Reset** (zobrazené len pre príznaky pochádzajúce z `DB`) na zrušenie prepísania
  a tlačidlo **Reset All Overrides** (Resetovať všetky prepísania) na spodku.
- Banner **Restart Server** (Reštartovať server), keď sa zmení príznak `requiresRestart`.

### REST API

Všetky operácie prebiehajú cez jednu cestu:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Každá metóda vyžaduje autentifikovanú dashboard reláciu (`401` inak).

#### `GET /api/settings/feature-flags`

Vráti každý príznak s jeho efektívnou hodnotou, zdrojom a súhrnom.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... all 77 flags
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Nastaví alebo odstráni jedno prepísanie. Telo: `{ key: string; value?: string }`.
Vymazanie `value` odstráni prepísanie (obnoví env / predvolené).

```bash
# Set a DB override
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Remove the override (no "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Odpoveď zopakuje novú `effectiveValue`/`source`, `previousValue`/
`previousSource` a `requiresRestart`. Neznáme kľúče a enum hodnoty mimo rozsahu
sú odmietnuté s `400`.

#### `DELETE /api/settings/feature-flags`

Vymaže **všetky** prepísania DB naraz, čím obnoví každý príznak na jeho env /
predvolenú hodnotu. Vráti `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Príznaky s `requiresRestart: true` sa prejavia až po opätovnom načítaní procesu.
> Tok reštartu dashboardu volá `POST /api/restart` a potom opakovane kontroluje
> `GET /api/health/ping`, kým sa server nespustí.

## Núdzový záložný mechanizmus pri vyčerpaní rozpočtu

`OMNIROUTE_EMERGENCY_FALLBACK` (kategória `runtime`, predvolená hodnota `true`) riadi
núdzové bezplatné záložné smerovanie v súbore
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Keď je povolené, požiadavky, ktoré vyčerpajú svoj rozpočet, sa namiesto okamžitého
zlyhania presmerujú na bezplatného záložného poskytovateľa/model. Ak chcete toto
správanie zakázať a nechať požiadavky s vyčerpaným rozpočtom zlyhať, nastavte
hodnotu na `false` (alebo `0`) — pomocou prepínača na ovládacom paneli, prepísania
v databáze alebo premennej prostredia `OMNIROUTE_EMERGENCY_FALLBACK`.
(V PR #3741 / #3752 je táto možnosť sprístupnená ako prepínač na ovládacom paneli.)

Odpoveď poskytnutá týmto záložným mechanizmom obsahuje hlavičku
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`, takže
klient dokáže zistiť, že bola presmerovaná, bez porovnávania hlavičky
`X-OmniRoute-Provider` so svojou požiadavkou. Vo všetkých ostatných odpovediach
táto hlavička chýba.
