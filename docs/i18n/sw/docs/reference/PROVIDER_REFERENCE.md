Jumla ya watoa huduma: **359**. Tazama mgawanyo wa kategoria hapa chini.

## Kategoria

- **Bure** — kiwango cha bure na ufunguo wa API (umesanidiwa kupitia dashibodi)
- **Hakuna-auth** — vituo vya umma ambavyo havihitaji ufunguo au kuingia kabisa
- **OAuth** — mtiririko wa kuingia unaoshughulikiwa na OmniRoute, hakuna ufunguo wa API unaohitajika
- **Kuki ya wavuti** — hufunga programu ya wavuti ya mtoa huduma kupitia uthibitishaji wa kuki
- **Ufunguo wa API** — mtoa huduma anayelipwa aliyesanidiwa kupitia ufunguo wa API (mikopo ya bure inaweza kutumika)
- **Ndani** — huendeshwa kwenye mashine ya mtumiaji (Ollama, LM Studio, vLLM, n.k.)
- **Tafuta** — watoa huduma wa utafutaji wa wavuti
- **Sauti** — watoa huduma wa sauti pekee (TTS/STT)
- **Proksi ya juu** — watoa huduma wanaopitisha kwa watoa huduma wengine
- **Wakala wa wingu** — mawakala wa usimbaji wanaofanya kazi kwa muda mrefu (Codex Cloud, Devin, Jules)
- **Mfumo** — watoa huduma wa ndani wa OmniRoute (loopback, n.k.)

Vitambulisho vya ziada: `picha`, `video`, `mkusanyaji`, `biashara`, `pachika/panga upya`, `iliyepangishwa mwenyewe`.

`Kupiga simu kwa zana` (pale inapoonyeshwa): `asili` — API halisi ya kupiga simu kwa kazi; `iliyoigwa` — safu ya `zana` imeigwa kwa haraka kupitia `webTools.ts` (vizuizi vya `<tool>{...}</tool>` vilivyochanganuliwa kwa regex); `hakuna` — `zana` kwa sasa huachwa kimya kimya. Tazama #7286.

Tumia dashibodi kwenye `/dashboard/providers` kuwezesha, kusanidi, na kujaribu kila mtoa huduma.
